# EstateVista — Luxury Real Estate

A premium, responsive real estate website concept showcasing a curated collection of luxury homes and distinctive properties.

## Features

- Editorial-style luxury real estate design
- Responsive layout for desktop, tablet, and mobile
- Property cards with location, price, and home details
- Search properties by location or keyword
- Filter by property type and maximum price
- Sort listings by price
- Save/unsave properties with a favorite control
- Mobile navigation menu
- Accessible labels and reduced-motion support

## Built With

- HTML5
- CSS3 (Flexbox, Grid, custom properties, media queries)
- Vanilla JavaScript

## Run Locally

1. Clone the repository:
   ```bash
   git clone YOUR_REPOSITORY_URL
   ```
2. Open the project folder.
3. Open `index.html` in your browser.

No build step or framework is required.

## Notes

This is a frontend demonstration project. Listings, prices, locations, and contact details are sample content, not verified property offers. The search and filters operate on the sample listings included in the page; there is no property database or booking backend.

The photography is loaded from Unsplash image URLs and therefore requires an internet connection. Replace images with appropriately licensed assets before using the project commercially.
